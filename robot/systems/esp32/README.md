# ESP32: нижний уровень привода

Плата стоит на самом роботе и крутит моторы через два ESC. Расба ей приказывает,
она исполняет и следит, чтобы робот не уехал сам по себе.

Поэтому папка лежит **внутри `robot/systems/`**, а не в корне репозитория:
ESP32 — такая же система робота, как лидар или сервоприводы, просто её код
исполняется на другом кристалле.

```
esp32/
  uart_protocol.h            контракт линии, общий для обеих сторон
  motor_driver/              прошивка ESP32 (скетч Arduino IDE)
```

## Контракт линии

Формат записан один раз в [`uart_protocol.h`](uart_protocol.h). Его подключают
обе стороны: драйвер `robot/systems/rpi/drive/drive_controller.cpp` и прошивка.
Правишь формат — правь этот файл, а не одну из сторон.

```
Команда:    R:<percent>%|L:<percent>%\n      percent = -100..100
Телеметрия: S:<0|1>|N:<counter>\n            датчик звука, раз в 100 мс
```

Линия: UART1, RX = GPIO20, TX = GPIO21, 115200 бод, 8N1, без управления потоком,
уровни 3.3 В, общая земля. TX отправителя идёт на GPIO20.

Отправитель обязан повторять команду: после `COMMAND_TIMEOUT_MS` (500 мс) тишины
прошивка сама глушит оба мотора. Это последний рубеж — он срабатывает и когда
расба зависла, и когда провод отвалился, то есть ровно тогда, когда программные
защиты уже не работают.

Телеметрию звука расба сейчас не читает: строка уходит в линию, но приёмника у
неё на стороне `systems/rpi/drive` нет.

## Прошивка

`motor_driver/motor_driver.ino` — Arduino IDE, библиотека `ESP32Servo`, плата
ESP32-C3 Super Mini. Для отладочного вывода по USB: `USB CDC On Boot = Enabled`.

Подключение и калибровка, проверенные на стенде:

| | |
|---|---|
| ESC правое / левое | GPIO3 / GPIO4 |
| Направление | оба канала инвертированы (`RIGHT_DIRECTION = LEFT_DIRECTION = -1`) |
| Шкала | 100 % = 150 мкс от нейтрали 1500 мкс |
| Выравнивание | `LEFT_TRIM_US = 2`, `LEFT_GAIN_PERMILLE = 900` |
| Датчик звука | LM393, цифровой выход на GPIO10 |

`LEFT_GAIN_PERMILLE` подбирали прогоном по полу, а не на подставке: робота уводило
влево, поэтому левое колесо замедлено до 90 %. Если поменяются моторы, ESC или
покрытие — подбирать заново, шагом 50.
